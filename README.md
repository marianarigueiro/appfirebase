## Tema escolhido
Grandes Obras de Engenharia Civil — um catálogo de imagens detalhadas de pontes
estaiadas, barragens e arranha-céus em construção, cadastrado pelo próprio usuário
autenticado no app.

## Tecnologias
- Jetpack Compose
- Firebase Authentication (E-mail/Senha)
- Cloud Firestore
- Coil (carregamento de imagens via URL)

## Funcionalidades
- Cadastro e login de usuário
- CRUD de obras de engenharia (título, tipo, localização, descrição e imagem),
  vinculado ao usuário logado
- Interface com identidade visual própria (paleta de aço/concreto e laranja de obra)

## Como rodar
1. Clone o repositório
2. Abra no Android Studio
3. Conecte seu próprio projeto Firebase (Tools > Firebase) ou use o `google-services.json` fornecido
4. Rode em um emulador ou dispositivo físico
